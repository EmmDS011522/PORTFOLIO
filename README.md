# Emman DS - Modern Multidisciplinary Portfolio Website

A clean, aesthetic, and modern personal portfolio website built exclusively with **vanilla HTML5, CSS3, and JavaScript**. Designed with a sophisticated obsidian dark theme, soft purple ambient glow accents, and crisp white typography.

---

## 🚀 Live Preview / Opening the Portfolio
To view the portfolio website locally:
1. Double-click or open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
2. Alternatively, if you have VS Code with the "Live Server" extension, right-click `index.html` and click **"Open with Live Server"**.
3. You can also run a quick local server using Python or Node if desired:
   ```bash
   # Using Python
   python -m http.server 3000
   ```
   Then navigate to `http://localhost:3000` in your browser.

## 🎨 Design & Aesthetic Highlights
- **Palette**:
  - **Backgrounds**: Obsidian Deep Black (`#08070d`, `#0e0c16`, `#141124`)
  - **Accents**: Soft Radiant Purples (`#c084fc`, `#a855f7`, `#7c3aed`)
  - **Typography**: Crisp Pure White (`#ffffff`), Slate Gray (`#cbd5e1`), Muted Silver (`#94a3b8`)
- **Visual Features**:
  - **Glassmorphism**: Backdrop blur with subtle translucent borders.
  - **Ambient Glows**: Soft blurred radial gradients providing depth without visual clutter.
  - **Modern Typography**: Google Fonts (*Plus Jakarta Sans* for clean headings/body, *JetBrains Mono* for technical specs and code tags).
  - **Hover Micro-interactions**: Smooth card elevation, glowing border highlights, and interactive button transitions.
  - **Scroll Reveal**: Fade-in and slide-up animations triggered via `IntersectionObserver`.
